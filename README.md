AI Assistant

An AI-powered web assistant built with Python and Flask that allows users to interact with an AI model through a simple and user-friendly web interface.

About the Project

This project was built to gain practical experience working with AI APIs and integrating AI capabilities into a web application.

The application sends the user's message to an AI model through an API and displays the generated response on the web interface.

Features

- Chat with an AI assistant
- Simple and responsive web interface
- Real-time AI-generated responses
- API integration using the OpenAI SDK
- Secure API key management using environment variables

Technologies Used

- Python
- Flask
- OpenAI API
- OpenAI Python SDK
- HTML
- CSS
- python-dotenv

How It Works

1. The user enters a question or message in the web interface.
2. Flask receives the user's input.
3. The application sends the request to the AI model through the OpenAI API.
4. The AI generates a response.
5. The response is displayed back to the user.

- Working with APIs
- Using the OpenAI Python SDK
- Reading and understanding API documentation
- Sending requests to AI models
- Managing API keys using `.env` files
- Connecting a Python backend with an HTML/CSS frontend
